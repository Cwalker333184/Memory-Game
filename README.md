#  Animal Memory Game

A fun and simple memory card game built using HTML, CSS, and JavaScript. Match pairs of animal emojis to win!

## How to Play

- Click on a card to flip it.
- Flip another card to find its match.
- If the two cards match, they stay flipped.
- If they don’t match, they flip back after a second.
- Match all pairs to win the game!
- A **“You Win!”** message will appear when you’ve found all pairs.

##  Technologies Used

- HTML5
- CSS3 (Flexbox + Grid)
- JavaScript (DOM Manipulation)

##  Features

- Smooth card flipping animation
- Emoji-based animal icons
- Win detection and restart option
- Responsive, centered layout using CSS Grid

**Enjoy the game and feel free to customize the cards, emojis, or styling!**
